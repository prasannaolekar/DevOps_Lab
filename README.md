\# DevOps Lab



\## Overview

This repository contains hands-on DevOps exercises covering containerization, CI/CD, Kubernetes, monitoring, and application deployment. Each exercise is organized in its own folder with relevant source code, configuration files, and screenshots.



\## Technologies

\- Git and GitHub

\- Docker and Docker networking

\- Kubernetes and Minikube

\- Jenkins and CI/CD pipelines

\- Python and Flask

\- Prometheus and Grafana

\- Docker AppArmor security

\## Repository Structure

Each exercise may include:

\- Application source code

\- Dockerfiles and Kubernetes YAML manifests

\- Jenkins pipeline configuration

\- Screenshots of implementation and verification

\- An exercise-specific README



\## Learning Objectives

\- Build and run containerized applications.

\- Configure Docker networking and security.

\- Automate build and test workflows with Jenkins.

\- Deploy and scale applications on Kubernetes.

\- Configure Services, replicas, and pod scheduling.

\- Monitor and verify application deployments.



\## How to Use

1\. Select an exercise from the table above.

2\. Open its folder and read the exercise-specific README, if available.

3\. Follow the implementation commands and inspect the configuration files.

4\. Review the screenshots for execution and verification evidence.
