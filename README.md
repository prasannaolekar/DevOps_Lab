\# DevOps Lab



\## Overview

This repository contains hands-on DevOps exercises covering containerization, CI/CD, Kubernetes deployments, monitoring, and application management. Each exercise is organized into its own folder with source code, configuration files, and screenshots where applicable.



\## Technologies

\- Git and GitHub

\- Docker

\- Kubernetes and Minikube

\- Jenkins

\- Python and Flask

\- Prometheus and Grafana
